# CyberForum - Web Project #5

A modern, responsive mini forum application with live interactions.

## Features
* **Dark/Light Theme:** Fully integrated dynamic appearance switcher.
* **Account Creation:** Secure password policy validator (8+ characters, uppercase, and digits).
* **Live Feed System:** Users can publish posts instantly without page reloads.
* **Interactive Content:** Like, dislike, and thread-specific custom comment replies.

## Technologies Used
* HTML5
* CSS3 (Custom Dark Theme UI)
* Vanilla JavaScript (DOM Manipulation & Custom Event Listeners)
